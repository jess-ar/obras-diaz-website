# Obras Díaz Website

Proyecto de sitio web corporativo para Obras Díaz 2011, S.L. construido con React + Vite + Tailwind.

## Requisitos

- Node.js 18 o superior
- pnpm

## Instalación

```bash
pnpm install
```

## Desarrollo

```bash
pnpm dev
```

## Build de producción

```bash
pnpm build
```

## Estructura recomendada

- `public/` para archivos estáticos como favicons, robots.txt o imágenes locales
- `src/` para la lógica y componentes de la aplicación
